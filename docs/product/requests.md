# Client requests

Every feature a client asks for, from the first conversation to the built
app. One row per request; newest first. The steps are in
[`demo/README.md`](../../demo/README.md#from-client-request-to-built-feature).

| Status | Meaning |
|---|---|
| Requested | Asked for; not yet in the demo |
| Prototyped | Working in the demo, waiting for the client to agree |
| Agreed | Client agreed; PRD section written with acceptance criteria |
| Built | Live in the app on `main`; PRD and demo label say Built |
| Declined | Client or we decided not to do it (say why in Notes) |
